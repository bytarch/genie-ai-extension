# Genie AI Extension

The Genie AI extension enhances your browsing experience with smart features tailored for efficiency and ease of use.

**Download Links:**
- [Release Page](https://github.com/bytarch/genie-ai-extension/releases)
- [Direct Download (v1.0.0)](https://github.com/bytarch/genie-ai-extension/releases/download/v1.0.0/genie.crx)

## Installation Guide

### Google Chrome
1. Download the Genie AI extension CRX file from the links above.
2. Open Chrome and drag-and-drop the downloaded <code>genie.crx</code> file onto the <a href="chrome://extensions/" class="text-blue-600 hover:underline">chrome://extensions/</a> page.
3. Confirm the installation if prompted.

### Mozilla Firefox
1. Download the Genie AI extension CRX file from the links above.
2. Open Firefox and go to <a href="about:debugging#/runtime/this-firefox" class="text-blue-600 hover:underline">about:debugging#/runtime/this-firefox</a>.
3. Enable <strong>Enable add-on debugging</strong> if it's not already enabled.
4. Click on <strong>Load Temporary Add-on...</strong> and select the downloaded <code>genie.crx</code> file.

### Opera
1. Download the Genie AI extension CRX file from the links above.
2. Open Opera and drag-and-drop the downloaded <code>genie.crx</code> file onto the <a href="opera://extensions/" class="text-blue-600 hover:underline">opera://extensions/</a> page.
3. Confirm the installation if prompted.

### Viewing the Extension Image
You can click on the text "Show Image" in the Genie AI Extension page to view a screenshot of the extension in a modal.

Keep enjoying the enhanced capabilities of the Genie AI extension!
