Installation Guide

Google Chrome

  1. Download the Genie AI extension CRX file from the links above.
  2. Open Chrome and drag-and-drop the downloaded genie.crx file onto the chrome://extensions/ page.
  3. Confirm the installation if prompted.

Mozilla Firefox

  1. Download the Genie AI extension CRX file from the links above.
  2. Open Firefox and go to about:debugging#/runtime/this-firefox.
  3. Enable Enable add-on debugging if it's not already enabled.
  4. Click on Load Temporary Add-on... and select the downloaded genie.crx file.

Opera

  1. Download the Genie AI extension CRX file from the links above.
  2. Open Opera and drag-and-drop the downloaded genie.crx file onto the opera://extensions/ page.
  3. Confirm the installation if prompted.

Keep enjoying the enhanced capabilities of the Genie AI extension!
