# Genie AI Extension

The Genie AI extension enhances your browsing experience with smart features tailored for efficiency and ease of use. 

**Download Links:**
- [Release Page](https://github.com/bytarch/genie-ai-extension/releases)
- [Direct Download (v1.0.0)](https://github.com/bytarch/genie-ai-extension/releases/download/v1.0.0/genie_extension.zip)

## Installation Guide

### Google Chrome
1. Download the Genie AI extension zip file from the links above.
2. Extract the zip file to a folder on your computer.
3. Open Chrome and go to chrome://extensions/.
4. Enable Developer mode by toggling the switch in the top right corner.
5. Click on Load unpacked and select the folder where you extracted the extension.

### Mozilla Firefox
1. Download the Genie AI extension zip file from the links above.
2. Extract the zip file to a folder on your computer.
3. Open Firefox and go to about:debugging#/runtime/this-firefox.
4. Enable Enable add-on debugging if it's not already enabled.
5. Click on Load Temporary Add-on... and select the manifest.json file from the extracted folder.

### Opera
1. Download the Genie AI extension zip file from the links above.
2. Extract the zip file to a folder on your computer.
3. Open Opera and go to opera://extensions/.
4. Enable Developer mode by toggling the switch in the top right corner.
5. Click on Load unpacked and select the folder where you extracted the extension.

### Viewing the Extension Image
You can click on the text "Show Image" in the Genie AI Extension page to view a screenshot of the extension in a modal.

Keep enjoying the enhanced capabilities of the Genie AI extension!
